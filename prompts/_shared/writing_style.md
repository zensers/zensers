# Writing Style Guidelines

## Basic Principles

1. Output analysis content directly, prohibit any conversational prefixes
2. Each paragraph starts with a clear judgment statement, directly stating the core viewpoint
3. Data and analysis should flow naturally, avoid segmented facts/opinions
4. Prohibit adding source annotations in the body text, such as (Source: XXX, Confidence: XX)
5. Avoid colloquial expressions

## Prohibited Expressions

### Colloquial Expressions (Prohibited)
- "Worth noting"
- "Coincidentally"
- "Interestingly"
- "Have to say"
- "Let's look at"
- "Imagine"
- "Did you know"
- "This means"
- "In other words"
- "Simply put"

### Source Annotations (Prohibited)
- (Multiple institutions predict)
- (Data shows)
- (According to research)
- [Source: xxx]
- [Source 15]

### Analysis Tags (Prohibited)
- "Original insight"
- "We believe"
- "Analysis shows"

## Correct Expression Style

### Data Presentation
- ✅ Present data directly, no need to explain data source or origin
- Example: The 15.2% year-over-year growth slowed significantly from 2025's 28.2%, but the absolute increment still reached about 3 million units.

### Judgment Presentation
- ✅ Present conclusions directly, no transitional colloquialisms
- Example: China's new energy vehicle market is at a critical stage of transitioning from policy-driven to market-driven growth.

### Paragraph Structure
- ✅ Each paragraph starts with a judgment statement
- ✅ Judgment followed by data support
- ✅ Provide the meaning behind the data
