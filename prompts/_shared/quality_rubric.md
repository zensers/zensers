# Quality Evaluation Rubric

## Scoring Dimensions (0-100 scale)

### 1. Completeness (25 points)
- **20-25**: All required sections present, data coverage >80%, key aspects addressed
- **15-19**: Most sections present, data coverage 60-80%, minor gaps
- **10-14**: Missing key sections, data coverage 40-60%, significant gaps
- **0-9**: Major sections missing, data coverage <40%, fundamental incompleteness

### 2. Accuracy (25 points)
- **20-25**: All data points verifiable, calculations correct, no contradictions
- **15-19**: Minor calculation errors (<5%), isolated data inconsistencies
- **10-14**: Multiple errors (5-15%), some unverified claims
- **0-9**: Major factual errors, fabricated data, systematic inaccuracies

### 3. Analytical Depth (25 points)
- **20-25**: Multi-framework analysis, causal chains explained, counter-evidence considered
- **15-19**: Single framework applied well, some causal reasoning, limited counter-evidence
- **10-14**: Surface-level analysis, descriptive not analytical, no counter-evidence
- **0-9**: No analytical framework, pure data listing, no insights

### 4. Logical Consistency (15 points)
- **12-15**: No internal contradictions, conclusions follow from premises, coherent narrative
- **8-11**: Minor inconsistencies, mostly coherent with isolated logical gaps
- **4-7**: Multiple contradictions, conclusions not fully supported
- **0-3**: Fundamental logical flaws, incoherent narrative

### 5. Writing Quality (10 points)
- **8-10**: Professional tone, clear structure, no colloquialisms, proper terminology
- **5-7**: Generally professional, minor style issues, adequate structure
- **2-4**: Informal language, poor structure, terminology issues
- **0-1**: Unprofessional, disorganized, inappropriate style

## Pass Threshold
- **Overall score >= 60**: Pass
- **Any dimension < 10**: Automatic fail (critical deficiency)
- **High-severity issues > 1**: Conditional pass (requires revision)

## Issue Severity Classification

### High Severity (blocks pass)
- Fabricated data or citations
- Fundamental logical contradictions
- Missing required sections (market size, competitive landscape, etc.)
- Major calculation errors affecting conclusions

### Medium Severity (triggers revision)
- Unsupported claims without evidence
- Incomplete data coverage (<60%)
- Missing counter-evidence consideration
- Internal inconsistencies in non-critical sections

### Low Severity (logged but passes)
- Minor style issues
- Suboptimal structure
- Missing optional enhancements
- Minor data gaps in non-critical areas

## Self-Evaluation Checklist
Before submission, verify:
1. All required sections present and complete
2. Data sources cited (internally, not in output)
3. Calculations double-checked
4. Counter-evidence addressed
5. No colloquial expressions
6. Conclusions supported by presented data
7. Logical flow coherent across sections
