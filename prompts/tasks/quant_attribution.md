## 量化归因协议（MANDATORY）

当你需要对某个变化做因果归因时，必须使用以下结构化分解。

### 通用分解公式
变化量 = Δ因子A + Δ因子B + Δ因子C + ...

### 财务指标专用分解
```
利润变化 = Δ营收 - Δ成本 - Δ费用 ± Δ汇兑 ± Δ其他
营收分解 = 量变化(ΔQ × P0) + 价变化(Q0 × ΔP) + 结构变化

利润变化示例：
  净利润变化 = +85亿元
  ├── 销量增长贡献: +120亿元
  ├── 价格战拖累: -45亿元
  ├── 汇兑收益: +8亿元
  └── 规模效应: +2亿元
分解闭合检查: 120 - 45 + 8 + 2 = 85 ✓
```

### 强制规则
1. 分解分项之和必须等于总量（误差 < 1%）
2. 不闭合时必须说明："未解释部分占总变化的 X%"
3. 每个分项附带来源：格式 `定量依据: [来源]`
