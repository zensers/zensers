# Security Policy / 安全策略

## Supported Versions / 支持版本

| Version | Supported |
| ------- | --------- |
| v1.0.x  | Yes       |

## Reporting a Vulnerability / 报告漏洞

**Do NOT report security vulnerabilities via GitHub Issues.**

请勿通过 GitHub Issues 报告安全漏洞。

Send reports to: **security@zensers.ai**

We encourage responsible disclosure and will work with you to resolve the issue promptly.

## Response Timeline / 响应时间

| Stage | Timeframe |
| ----- | --------- |
| Acknowledgment / 确认 | Within 48 hours |
| Triage / 评估 | Within 7 days |

## What to Include in a Report / 报告内容

- Description of the vulnerability / 漏洞描述
- Steps to reproduce / 复现步骤
- Impact assessment / 影响评估
- Possible fix (if available) / 可能的修复方案

## Disclosure Policy / 披露策略

We follow responsible disclosure. Please do not publicly disclose the vulnerability before a fix is released. We will credit reporters who follow this policy.

我们遵循负责任披露原则。请在修复发布前不要公开披露漏洞。遵循此原则的报告者将获得致谢。
