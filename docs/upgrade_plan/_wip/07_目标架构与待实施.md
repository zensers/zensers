### 4.2 目标架构

```python
class SemanticQualityScorer:
    async def score(self, content, section_type, framework=None):
        layer1 = await self._layer1_structure(content, section_type)
        if layer1.score < 30:
            return SectionScore(total=layer1.score, layers={"structure": layer1})
        layer2 = await self._layer2_methodology(content, section_type, framework)
        layer3 = await self._layer3_depth(content, section_type)
        total = layer1.score * 0.30 + layer2.score * 0.40 + layer3.score * 0.30
        return SectionScore(total=round(total, 1), layers={...})
```

### 4.3 Layer 1: 结构完整性检查 (30%) — 替代管道B关键词计数

**当前缺陷**（代码验证）:
- `_calculate_section_score` (quality_check_agent.py:809-813): 7个硬编码词`["核心判断", "逻辑推导", "数据支持", "反证", "边界条件", "意义", "影响"]`，`found/total`比例

- 不检查：量化分解、数据口径、反证深度

### 4.4 Layer 2: 方法论应用评估 (40%)

评估 Agent 是否正确应用了分析框架：

1. **框架匹配度**: 通过LLM识别内容使用的分析框架，与section_type预期框架对比
2. **组件覆盖率**: 框架各要素是否都被覆盖（利用MKB的FrameworkComponent）
3. **数据支撑度**: 框架分析是否有数据支撑（不只是"有数字"，而是"数据支撑了哪个论点"）
4. **逻辑一致性**: 通过LLM评估因果链完整性

**前置依赖**: MKB的AnalyticalFramework和QualityRubric必须先创建。

5. 可验证性 (15%)

  目标: 数据收集 → prompt构建 → LLM → 日期验证 → 迭代深化 → 【自评】 → 返回

**自评实现方案**:

```python
async def _self_evaluate(self, content: str, section_type: str) -> Dict:
    rubric = self._context.get("quality_rubric", "")
    if not rubric:
        return {"pass": True, "score": 100}
    
    prompt = f"""评估以下分析内容的质量（0-100分）。

评分标准：
{rubric}

分析内容（截取前3000字符）：
{content[:3000]}

请输出JSON：{{"score": <0-100>, "weak_dimensions": ["dim1", ...], "suggestions": ["sug1", ...]}}"""

    result = await self._call_llm(prompt, temperature=0.2)
    parsed = self._parse_json_response(result)
    return parsed

async def _auto_revise(self, content: str, eval_result: Dict) -> str:
    if eval_result.get("score", 100) >= 60:
        return content
    suggestions = eval_result.get("suggestions", [])
    revise_prompt = f"请根据以下建议修订分析内容：\n" + "\n".join(f"- {s}" for s in suggestions[:3])
    revised = await self._call_llm(f"{revise_prompt}\n\n原始内容：\n{content[:4000]}")
    return revised
```

**风险控制**:
- 自评增加1-2次LLM调用，需控制成本
- 自评不应替代QC，仅作为Agent内部的质量门控
- 自评结果不写入quality_state，避免与管道B冲突
