## 2. 依赖错误

### 2.1 A1 ↔ A3 依赖方向错误

**06 方案说**: A3 (QualityResult 标注分数尺度) 依赖 A1 (normalize 函数)

**实际**: A1 的 normalize 函数需要 `score_scale` 字段来消除自动检测歧义。A3 应**先于** A1 实施, 或是**同一批次**实施。

```python
# A1 的理想签名 (在 A3 之后):
def normalize_quality_score(
    score: float,
    score_scale: Optional[Literal["0-1", "0-100"]] = None,
) -> float:
    if score_scale == "0-100" or (score_scale is None and score > 1.0):
        return score
    if score_scale == "0-1" or (score_scale is None and 0.0 <= score <= 1.0):
        return score * 100.0
    return score  # fallback
```

**建议**: 将 A1 和 A3 合并为一个步骤, 或在依赖表中标注"互依赖"

### 2.2 A7 依赖 A4 不正确

**06 方案说**: A7 (自评指令) 依赖 A4 (方法论 token)

**实际**: 自评指令只需要 `quality_rubric` 已注入 prompt (v9.2 已完成 24/24), 不依赖方法论 token 从 150→800。A7 的前置条件已满足。

**建议**: 删除 A7 的 A4 前置依赖
