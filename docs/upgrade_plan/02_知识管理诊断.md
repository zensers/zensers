### 2.4 FTS5中文支持问题

FTS5默认tokenizer(`unicode61`)不支持中文分词：

```python
# fts/__init__.py:653 — _build_fts_query
def _build_fts_query(self, query):
    query = query.replace('"', '""')
    if ' ' in query:
        return f'"{query}"'  # 短语搜索
    return f'{query}*'  # 前缀搜索
```

| 查询 | FTS5 MATCH | SQL LIKE | 结论 |
|------|------------|---------|------|
| `"宁德时代"` | ✅ 精确匹配 | ✅ `%宁德时代%` | 等效 |
| `"宁德"` | ❌ 不匹配(单token) | ✅ `%宁德%` | **FTS5更差** |
| `"BEV"` | ✅ 前缀匹配 | ✅ `%BEV%` | 等效 |
| `"electric vehicle"` | ✅ 短语搜索 | ✅ `%electric vehicle%` | FTS5更好 |

**推荐**: FTS5+LIKE双路径——英文/缩写走FTS5，中文走LIKE，合并去重。

> ✅ **已修复 (2026-06-04)**: `_build_fts_query(:656-672)` 增加 jieba 中文分词路径——检测 `[\u4e00-\u9fff]` 后经 jieba 分词为短语搜索 `"token1 token2"`，非中文保持前缀/短语搜索。jieba 不可用时透明回退。

**缺陷**:
- 纯计数无时间衰减：100次研究中提到5次与1次研究中提到5次权重相同

> ✅ **三项已修复 (2026-06-04)**: (1) `_sort_and_limit_entities(:239-249)` 加入时间衰减因子——`decay = max(0.9, 1.0 - (days_ago/365)*0.5)`，`e._score = e.mention_count * decay` 后降序排序。(2) 新增 `_trim_to_fit(:598-604)` 方法，`save()` 超出10KB时调用，先排序再循环 pop 最低分实体直至满足限制。(3) 代码行号更新至608行。
