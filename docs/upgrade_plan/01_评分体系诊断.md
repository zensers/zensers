## 1. 评分架构全景

系统存在两条独立评分管线，最终融合为一个分数：

```
管线 A: 编排器阶段检查器 (src/core/orchestrator/execution/engine.py)
  └─ DataCollectionQualityChecker → AnalysisQualityChecker → ReportQualityChecker
     (每批次执行，阈值 70/70/80 [src/config/settings.py:209-211]，最多重试 3 次)
     注: checkers.py 硬编码默认值为 80/85/80，但引擎初始化时
         使用 settings.quality.threshold_*，实际生效的是配置值 70/70/80

管线 B: QualityCheckAgent 终检 (src/agents/fixed_agents/quality_check_agent.py)
  └─ 4 项全局检查 + check_by_sections 分章节检查
     (报告生成后执行，阈值 60)

最终融合: quality_score * 0.6 + section_overall * 0.4
  来源: quality_check_agent.py:173
```

### 1.1 管线 A 的实际执行流程

```
engine.py:1360-1455 (execute_with_scheduler 内的 QC 逻辑块)
  │
  ├─ _select_checker_for_batch() 根据批次内容路由检查器
  │   ├─ 有 data_points + sources 但无 content → DataCollectionQualityChecker
  │   ├─ 有 content → CompositeChecker(Analysis 70% + LLMJudge 30%)
  │   └─ 其他 → DataCollectionQualityChecker (默认)
  │
  ├─ 构建 check_data 时硬编码 quality_score=50.0 ← 关键遗漏
  │   来源: engine.py:1389, engine.py:1440
  │
  └─ QC 不通过时重试 (max_retries 次)，全部耗尽后继续执行（不阻塞）
```

## 2. DataCollectionQualityChecker

**代码**: `checkers.py:218-314`
**阈值**: 80.0 (硬编码 `checkers.py:234`)，实际生效 70 (src/config/settings.py:209)
**公式**: `volume * 0.3 + quality_score * 0.4 + source_score * 0.3` (`checkers.py:267`)

### 2.1 数据量 (30%)

**代码**: `checkers.py:271-286`

```python
def _calculate_volume_score(self, metadata: Dict[str, Any]) -> float:
    data_volume = metadata.get("data_volume", 0)
    if data_volume >= 100: return 100.0
    elif data_volume >= 50: return 80.0
    elif data_volume >= 20: return 60.0
    elif data_volume >= 10: return 40.0
    elif data_volume >= 5: return 20.0
    else: return 10.0
```

**局限**: 粗粒度分桶——99条和50条同分(80)，纯计数不衡量相关性。

### 2.2 质量分 (40%) — 存在双重锚定问题

**代码**: `checkers.py:261`

```python
quality_score = quality_metadata.get("quality_score", 50.0)
```

**问题链**:
1. `QualityMetadata` 默认值为 50.0 (`metadata_extractor.py:55`)
2. 异常时也回退 50.0 (`metadata_extractor.py:205`)
3. **更严重**: `engine.py:1389,1440` 构建 check_data 时**硬编码** `quality_score=50.0`，即使 metadata_extractor 计算了实际分数也被覆盖

```python
# engine.py:1386-1390
"quality_metadata": {
    "data_volume": len(all_data_points) or len(all_sources),
    "sources": all_sources,
    "quality_score": 50.0,  # ← 硬编码，永远50，metadata_extractor 的计算结果被丢弃
},
```

**后果**: 40% 权重永远贡献 20 分 (50×0.4)，无论数据实际质量如何。

### 2.3 来源可信度 (30%)

**代码**: `checkers.py:288-309`

```python
authoritative_keywords = [
    "gov", "政府", "official", "官方", "report", "报告",
    "statistics", "统计局", "association", "协会",
]
authoritative_ratio = authoritative_count / len(sources) if sources else 0
return 80.0 * authoritative_ratio + 30.0 * (1 - authoritative_ratio)
```

**局限**: 仅10个关键词判定权威性；权威比例再高封顶80分；无来源时默认30分。

**注意**: `metadata_extractor.py:112-123` 已有更精细的 TIER1/TIER2 分级（含 reuters/bloomberg/mckinsey 等），但 `DataCollectionQualityChecker` 未使用此分级，而是自行用 10 个关键词重新判定。

### 2.4 典型得分演算

- 数据量30条 → 60分 × 30% = 18
- quality_score 硬编码 50 × 40% = 20
- 3/10来源含"官方" → ratio=0.3 → 80×0.3+30×0.7=45 × 30% = 13.5
- **总分 ≈ 51.5** → 落在40-60区间

## 3. AnalysisQualityChecker

**代码**: `checkers.py:347-426`
**阈值**: 85.0 (硬编码 `checkers.py:368`)，实际生效 70 (src/config/settings.py:210)
**公式**: `structure * 0.40 + caliber * 0.30 + counter * 0.20 + quant * 0.10` (`checkers.py:379-384`)

### 3.1 结构完整性 (40%)

**代码**: `checkers.py:386-392`

```python
STRUCTURE_MARKERS = {
    "core_judgment": ["核心判断", "核心结论", "Core Judgment"],
    "data_support": ["数据来源", "Source", "来源", "数据显示", "据"],
    "causal_decomposition": ["贡献", "个百分点", "其中", "分解", "因为", "因此"],
    "counter_evidence": ["如果", "若", "边界条件", "风险在于", "但需注意", "当"],
    "implication": ["意味着", "含义", "对投资", "对决策", "建议"],
}

def _check_structure(self, content: str) -> float:
    segments_found = 0
    for section_name, markers in self.STRUCTURE_MARKERS.items():
        if any(m in content for m in markers):
            segments_found += 1
    return (segments_found / 5.0) * 100.0
```

**局限**: 关键词游戏——出现"如果"即表示"反证"满分，出现"贡献"即表示"因果分解"满分。

**作弊验证**: 一篇包含"核心判断...数据来源...如果...贡献...意味着"的文本，结构分 = 100，即使无任何实质分析。

### 3.2 数据口径覆盖率 (30%)

**代码**: `checkers.py:394-401`

```python
CALIBER_PATTERNS = [r"[A股|港股|美股|GAAP|IFRS]口径", r"含.*权益|不含.*权益", r"来源[：:].+"]

def _check_caliber_coverage(self, content: str) -> float:
    numeric_refs = re.findall(r'\d+\.?\d*\s*(亿元|亿美元|%|万辆|GWh|万元|元)', content)
    caliber_refs = sum(1 for p in self.CALIBER_PATTERNS if re.search(p, content))
    if len(numeric_refs) == 0:
        return 100.0
    ratio = caliber_refs / max(1, len(numeric_refs) * 0.3)
    return min(100.0, ratio * 100.0)
```

**局限**:
1. **空文本得满分**: nums=0 → return 100.0 (`:398-399`)
2. **正则 bug**: `[A股|港股|美股|GAAP|IFRS]口径` 使用字符类 `[]` 而非交替组 `(?:...)`。`[A股|港股|美股|GAAP|IFRS]` 匹配的是**单个字符**集合 {A,股,|,港,美,G,P,I,F,R,S}，而非预期的多字符交替。实际效果："A口径"、"G口径"、"|口径" 能匹配，但 "A股口径"、"港股口径" 不能匹配
3. 口径仅检查3个正则模式

### 3.3 反证完整性 (20%)

**代码**: `checkers.py:403-408`

```python
def _check_counter_evidence(self, content: str) -> float:
    for markers in self.STRUCTURE_MARKERS["counter_evidence"]:
        if markers in content:
            return 100.0
    return 0.0
```

**局限**: **Binary: 0或100**。全文任意位置出现"如果"→满分，缺失→0分。这是全系统最脆弱的子维度。

### 3.4 量化分解率 (10%)

**代码**: `checkers.py:410-416`

```python
def _check_quantified_decomposition(self, content: str) -> float:
    patterns = [r'其中.*贡献.*\d+', r'分解为.*\d+.*\d+', r'\d+.*个百分点.*源于']
    for p in patterns:
        if re.search(p, content):
            return 100.0
    return 0.0
```

**局限**: **Binary: 0或100**，仅3个正则模式。用英文"driven by"等则漏检。

### 3.5 诊断总结

所有子维度都可以通过插入关键词作弊。一篇包含"核心判断...数据来源...如果...贡献...意味着"的文本可获得80+分，无论实际分析质量如何。

**得分模拟**:
- 作弊文本: structure=100, caliber=100(无数字), counter=100, quant=100 → **总分=100**
- 优质英文分析: structure=40(仅"Source"匹配), caliber=0, counter=0, quant=0 → **总分=16**
- 中文专业分析(无关键词): structure=0, caliber=50, counter=0, quant=0 → **总分=15**

**代码**: `llm_judge.py:18-132`
**权重**: 规则检查器70% + LLM Judge 30% (CompositeChecker配置, `engine.py:1724`)

### 4.1 回退机制

**代码**: `llm_judge.py:39-46`

```python
except Exception as e:
    logger.warning(f"LLM judge failed: {e}, falling back to rules")
    return 75.0  # :41 异常时回退75
if not scores:
    # CompositeChecker threshold=70, weight=0.3
    # 公式: 0.7 × analysis + 0.3 × llm_judge >= 70
```

**问题**: 失败应该扣分，而非加分。回退90的注释说明了设计意图——为了确保通过阈值，但这扭曲了评分分布。

**影响量化**:
| 场景 | LLM Judge 分数 | 所需 Analysis 分数 | 实际效果 |
|------|---------------|-------------------|----------|
| 正常工作 | 60 | 71.4 | 需要合格分析 |
| 异常回退 | 75 | 64.3 | 降低标准 |
| JSON解析失败 | 90 | 61.4 | 几乎必过 |

## 8. 可操作性修复方案

### 8.0 修复原则

1. **渐进式**: 每个修复独立可部署，不依赖其他修复
2. **可验证**: 每个修复有明确的验证方法（得分模拟/单元测试）
3. **风险可控**: 修复不改变评分量纲（仍为0-100），仅修正失真
4. **优先级驱动**: P0 修复可独立带来 +10~15 分提升

### 8.1 P0-1: 修复 engine.py 硬编码 quality_score=50.0

**文件**: `src/core/orchestrator/execution/engine.py`
**位置**: `:1386-1390`, `:1436-1441`
**预估工时**: 1-2 小时
**预期提升**: +5~10 分（DataCollectionQualityChecker 的 40% 权重恢复区分度）

**修复方案**:

```python
# 修改前 (engine.py:1386-1390)
"quality_metadata": {
    "data_volume": len(all_data_points) or len(all_sources),
    "sources": all_sources,
    "quality_score": 50.0,
},

# 修改后
def _build_quality_metadata(self, batch_results: List[Dict]) -> Dict:
    extracted_scores = []
    for r in batch_results:
        if r.get("success") and "quality_metadata" in r:
            qm = r["quality_metadata"]
            if isinstance(qm, dict) and "quality_score" in qm:
                qs = qm["quality_score"]
                if isinstance(qs, (int, float)) and qs != 50.0:
                    extracted_scores.append(float(qs))
    
    if extracted_scores:
        actual_score = sum(extracted_scores) / len(extracted_scores)
    else:

        ) if self.metadata_extractor else 50.0
    
    return {
        "data_volume": len(all_data_points) or len(all_sources),
        "sources": all_sources,
        "quality_score": actual_score,
    }
```

```python
    STRUCTURE_MARKERS = {
        "core_judgment": {
            "keywords": ["核心判断", "核心结论", "Core Judgment", "核心观点"],
            "context_required": True,
            "min_context_chars": 50,
        },
        "data_support": {
            "keywords": ["数据来源", "Source", "来源", "数据显示", "据"],
            "context_required": True,
            "min_context_chars": 30,
        },
        "causal_decomposition": {
            "keywords": ["贡献", "个百分点", "其中", "分解", "因为", "因此", "驱动", "拉动"],
            "context_required": True,
            "min_context_chars": 40,
        },
        "counter_evidence": {
            "keywords": ["如果", "若", "边界条件", "风险在于", "但需注意", "当",
                         "然而", "不过", "需要注意的是", "潜在风险", "不确定性"],
            "context_required": True,
            "min_context_chars": 30,
            "exclude_trivial": True,
        },
        "implication": {
            "keywords": ["意味着", "含义", "对投资", "对决策", "建议", "启示", "影响"],
            "context_required": True,
            "min_context_chars": 30,
        },
    }
    
    def _check_structure(self, content: str) -> float:
        segments_found = 0
        for section_name, config in self.STRUCTURE_MARKERS.items():
            keywords = config["keywords"]
            if config.get("context_required"):
                for kw in keywords:
                    idx = content.find(kw)
                    while idx != -1:
                        start = max(0, idx - 20)
                        end = min(len(content), idx + config.get("min_context_chars", 30))
                        context = content[start:end].strip()
                        if len(context) >= config.get("min_context_chars", 30):
                            if section_name == "counter_evidence" and config.get("exclude_trivial"):
                                if self._is_trivial_counter(kw, context):
                                    idx = content.find(kw, idx + 1)
                                    continue
                            segments_found += 1
                            break
                        idx = content.find(kw, idx + 1)
            else:
                if any(m in content for m in keywords):
                    segments_found += 1
        return (segments_found / 5.0) * 100.0
    
    @staticmethod
    def _is_trivial_counter(keyword: str, context: str) -> bool:
        trivial_patterns = [
            r"如果[你我他]", r"如果需要", r"如果.*可以", r"若要",
        ]
        return any(re.search(p, context) for p in trivial_patterns)
    
    def _check_counter_evidence(self, content: str) -> float:
        counter_indicators = [
            (r'(?:然而|不过|但是|但需|需要注意的是)[^。？]{10,}', 1.0),
            (r'(?:风险|不确定性|边界条件|限制|假设)[^。？]{10,}', 0.8),
            (r'(?:如果|若|当)[^。？]{15,}(?:则|那么|可能|将)', 0.6),
            (r'(?:如果|若)[^。？]{5,}', 0.2),
        ]
        max_score = 0.0
        for pattern, weight in counter_indicators:
            matches = re.findall(pattern, content)
            if matches:
                score = min(len(matches) / 3.0, 1.0) * weight * 100
                max_score = max(max_score, score)
        return max_score
    
    def _check_quantified_decomposition(self, content: str) -> float:
        patterns_strong = [
            r'其中[^。]*贡献[^。]*\d+',
            r'分解为[^。]*\d+[^。]*\d+',
            r'\d+[^。]*个百分点[^。]*源于',
            r'(?:驱动|拉动|贡献)[^。]*\d+\.?\d*\s*(?:%|个百分点)',
        ]
        patterns_partial = [
            r'(?:其中|分解)[^。]{5,}\d+',
            r'(?:增长|下降|变化)[^。]{3,}\d+\.?\d*\s*%',
        ]
        for p in patterns_strong:
            if re.search(p, content):
                return 100.0
        partial_count = sum(1 for p in patterns_partial if re.search(p, content))
        if partial_count >= 2:
            return 70.0
        if partial_count == 1:
            return 40.0
        return 0.0
```

```python
def _parse_response(self, response: str) -> Dict[str, float]:
    # 1. 尝试直接解析
    try:
        parsed = json.loads(response)
        if isinstance(parsed, dict):
            return parsed
    except (json.JSONDecodeError, ValueError):
        pass
    
    # 2. 提取 markdown 代码块中的 JSON
    code_block_match = re.search(r'```(?:json)?\s*(\{.*?\})\s*```', response, re.DOTALL)
    if code_block_match:
        try:
            parsed = json.loads(code_block_match.group(1))
            if isinstance(parsed, dict):
                return parsed
        except (json.JSONDecodeError, ValueError):
            pass
    
    # 3. 原始 find/rfind 回退
    s, e = response.find('{'), response.rfind('}') + 1
    if s >= 0 and e > s:
        try:
            parsed = json.loads(response[s:e])
            if isinstance(parsed, dict):
                return parsed
        except (json.JSONDecodeError, ValueError):
            pass
    
    return {}
```
