## 2. 各修复详细变更

### 2.1 P0-1: S2重试反馈断裂修复

**修改文件**:
- `src/core/orchestrator/execution/engine.py:1412-1427`
- `src/core/agents/generic_agent.py:249-253, 2915-2926`
- `src/core/orchestrator/execution/coordinator/agent_coordinator.py:400-401`

**变更内容**:

engine.py 在QC重试循环中注入 `quality_feedback` 到 `_a._context`:
```python
_a._context["quality_feedback"] = {
    "score": quality_result.score,
    "issues": quality_result.issues[:5],
    "previous_attempt": _qc_retries - 1,
}
```
同时写入SharedMemory（当`_shared_memory`存在时）。

generic_agent.py execute()新增读取逻辑:
```python
quality_feedback = self._context.get("quality_feedback", {})
if quality_feedback:
    self._quality_feedback = quality_feedback
else:
    self._quality_feedback = None  # 防止残留
```

generic_agent.py `_get_professional_role_prompt()`新增质量反馈注入:
```python
quality_feedback = getattr(self, '_quality_feedback', {})
if quality_feedback:
    base += "## 质量反馈（重试第N次）\n上次得分: XX\n需改进的问题:\n...\n"
```

agent_coordinator.py 新增 `_context["retry_attempt"]` 注入（之前只写入task dict）。

**闭环路径**:
```
engine QC失败 → _a._context["quality_feedback"] = {score, issues, previous_attempt}
  → agent.execute()读取 → self._quality_feedback = ...
    → _get_professional_role_prompt()注入 → LLM收到反馈改进分析
```

### 2.2 P0-2: 3个dangling方法实现

**修改文件**: `src/api/research_api.py:2860-2962`

**变更内容**:

- `_post_revision_recheck(session)`: 修订后重检，使用 `merge_issues_on_recheck` 合并新旧issue状态
  - 将dict转为QualityIssue Pydantic对象（CRIT-1修复）
  - 合并后推送SSE

- `_recheck_quality(session, sections, push_preview)`: 执行质量重检
  - 缓存QualityCheckAgent实例为`self._quality_checker`（CRIT-4修复）

- `_expire_stale_revising_issues(session)`: 过期revising状态issue
  - revising_since超过600秒→`max_retries_reached`
  - 无revising_since→`open`
  - 修订时写入`revising_since=time.time()`（IMP-6修复）

**新增import**: `import time` (research_api.py:31)

### 2.3 P0-3: 评分尺度统一0-100

**修改文件**:
- `src/core/orchestrator/execution/engine.py:2563-2574`
- `src/core/content_lock.py:66,119,285-294,330-340,385-403`

**变更内容**:

engine.py `_extract_quality_score()`:
- 默认值从1.0→50.0
- clamp范围从[0,1]→[0,100]
- 自动放大: `0.0 <= score < 1.0` → `score * 100.0`
  - CRIT-3修复: 使用`< 1.0`而非`<= 1.0`，避免1.0歧义

content_lock.py:
- `quality_score: float = 0.0` 注释更新 `(0-100)`
- `mark_completed` 默认值从1.0→100.0
- 范围检查从`0.0 <= quality_score <= 1.0`→`0.0 <= quality_score <= 100.0`
- 质量阈值比较新增自动放大: `threshold_100 <= 1.0` → `threshold_100 * 100.0`
- docstring示例从`quality_score=0.85`→`quality_score=85.0`
- CRIT-2修复: docstring缩进修正
