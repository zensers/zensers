# 统一重试方案（Coordinator QC 联动）

**版本**: v1.0
**日期**: 2026-06-05
**关联文档**: `03_Agent架构诊断.md` (v9.2), `04_待解决问题清单.md` (v9.2)
**对应问题**: 0.4 — agent_coordinator重试路径无QC联动

---

## 1. 架构总览

**核心变化**：将重试责任从 coordinator 上提到 engine，形成单一重试入口。

```
当前:
  Engine ──→ Coordinator(3次盲重) ──→ Engine QC重试(整个batch) ──→ 完成

方案B:
  Engine ──→ Coordinator(0次重试) ──→ Engine统一重试(只重试失败agent) ──→ 完成
                              ↓
                        失败agent + partial output + error info
```

**三个变更点**：
- Coordinator：去掉内部重试循环，改为捕获 failure type + partial output，立即返回
- Engine：扩展 QC 重试为通用重试，支持 infrastructure + quality 两种反馈，支持单个 agent 精准重试
- 结果合并：重试结果替换原始失败结果，下游无感知

## 2. Coordinator 改造

### 2.1 当前问题

`_execute_with_monitoring` 在 timeout/exception 时做内部循环重试（默认3次），且：
- 超时路径只注入 `retry_attempt`，无 quality_feedback
- 异常路径连 `retry_attempt` 都不注入
- agent 是盲重试，没有任何反馈

### 2.2 方案

去掉 while 循环，失败后捕获信息直接返回：

```python
async def _execute_with_monitoring(self, task, agent, timeout, ...):
    try:
        result = await agent.execute(task)
        active_task.result = result
        active_task.status = "completed"
    except asyncio.TimeoutError:
        active_task.status = "failed"
        active_task.error = f"Timeout after {timeout}s"
        active_task.failure_type = "timeout"
        active_task.partial_output = agent._context.get("last_output", "")
    except Exception as e:
        active_task.status = "failed"
        active_task.error = str(e)
        active_task.failure_type = "exception"
        active_task.partial_output = agent._context.get("last_output", "")
    # 不重试，engine 通过 wait_for_completion 拿到失败信息
```

### 2.3 `wait_for_completion` 返回值

failure 返回包含：
```python
{
    "success": False,
    "error": str(e),
    "agent_id": agent.agent_id,
    "failure_type": "timeout" | "exception",
    "partial_output": {...},
}
```

### 2.4 配置变更

```python
# coordinator 创建时
CoordinatorConfig(
    max_retries=1,  # 不再做内部重试
    ...
)
```

## 3. Engine 统一重试（核心）

### 3.1 重试流程

```
第一次执行 batch
       │
       ▼
_batch_results = await _execute_agents_batch(agents, ...)
       │
       ▼
_identify_failed_agents()
       │
       ├── success → QC检查 ──→ 通过 → 保留结果
       │                        └── 不通过 → quality_feedback注入 → 加入重试列表
       │
       └── failed (infra)
                └── quality_feedback注入(score=0, issues=错误信息) → 加入重试列表
       │
       ▼
while 重试列表非空 and retry_count < max_retries:
    retry_count += 1
    for 每个失败agent:
        await agent.reset()
        agent._context["retry_attempt"] = retry_count
        if infrastructure:
            agent._context["retry_reason"] = failure_type
            agent._context["previous_error"] = error
            agent._context["quality_feedback"] = {
                "score": 0,
                "issues": [f"Agent failed with {failure_type}: {error}"],
                "previous_attempt": retry_count - 1,
            }
        else:
            agent._context["quality_feedback"] = {
                "score": qc_result.score,
                "issues": qc_result.issues[:5],
                "previous_attempt": retry_count - 1,
            }

    # 只重试失败的agent（同一stage_name，同一batch上下文）
    _retry_results = await _execute_agents_batch(
        agents=[fa.agent for fa in 重试列表],
        requirement=requirement,
        previous_results=previous_results,
        scheduler=scheduler,
        stage_name=stage_name,  # 批次不变
    )

    # 重新评估本轮结果
    重试列表 = _identify_failed_agents(_retry_results)

if 重试列表非空:
    logger.warning(f"重试耗尽: {len(重试列表)}个agent仍失败")
```

### 3.2 反馈注入规则

| 失败类型 | 反馈内容 |
|---------|---------|
| quality | `quality_feedback.score` = QC分数, `issues` = QC问题列表 |
| timeout | `quality_feedback.score` = 0, `issues` = "Agent timed out" |
| exception | `quality_feedback.score` = 0, `issues` = "Agent failed with exception" |

### 3.3 计数器规则

- 统一计数器 `retry_count`，不区分 infra/quality
- 消耗 `engine.config.max_retries`（默认3次）
- 重试耗尽后记录告警，不阻断流程

## 4. 共享数据处理

| 数据 | 位置 | 策略 |
|------|------|------|
| `_context` | GenericAgent | 不重置，engine重试前注入 `quality_feedback` + `retry_attempt` |
| `_data` | LifecycleMixin | reset()清空，正确行为 |
| `_shared_memory` | CommunicationMixin | 不清理，重试写同一key覆盖 |
| `_knowledge_enrichment` | GenericAgent | 保留，不重新加载 |
| `message_bus` | 共享实例 | 不做处理，同一实例 |
| `previous_results` | engine参数 | 保留，成功agent结果不受影响 |

## 5. 结果合并

```python
def _merge_retry_results(batch_results, retry_results):
    merged = list(batch_results)
    for rr in retry_results:
        for i, br in enumerate(merged):
            if br.get("agent_id") == rr.get("agent_id"):
                merged[i] = rr
                break
    return merged
```

下游代码（QC记录、report拼接、metadata提取）不做任何修改。

## 7. 测试策略

### 7.1 Coordinator 不重试
- timeout 直接返回 failure，不循环
- 返回 failure 包含 `failure_type` + `error` + `agent_id`
- `partial_output` 捕捉正确

### 7.2 Engine 统一重试
- 区分 infra 和 quality 两种失败
- infra 注入 `retry_reason` + `previous_error`，quality 注入 `score` + `issues`
- 只重试失败 agent，成功 agent 不被打扰
- 重试耗尽后告警但不阻断
- 结果 merge 正确

### 7.3 端到端
- timeout → coordinator返回failure → engine捕获 → 注入feedback → 重试 → 成功 → merge
- QC不通过 → engine捕获 → 注入feedback → 重试 → 通过 → merge
- 重试后agent从 `_context` 正确读取 `quality_feedback`
