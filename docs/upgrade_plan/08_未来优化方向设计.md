## 4. Track B: 三层评分 Layer 2+3

**当前状态**: Layer 1 ✅ (SECTION_ELEMENT_REQUIREMENTS), Layer 2 ❌, Layer 3 ❌ (LLM Judge 已修但未升级)

### 4.1 Layer 2: 方法论应用评估

**输入**: 章节内容 + section_type + 匹配框架列表 (来自 MKB)
**输出**: `{"score": 0-100, "component_coverage": {id: bool}, "evidence_quality": 0-100}`

**实现**:
```python
class Layer2MethodologyScorer:
    async def score(self, content: str, section_type: str, frameworks: List[AnalyticalFramework]):
        results = []
        for framework in frameworks[:2]:  # 最多评估 2 个框架
            component_check = await self._check_components(content, framework.components)
            evidence_check = await self._check_evidence(content, framework.components)
            results.append({
                "framework": framework.name,
                "component_coverage": component_check,
                "evidence_quality": evidence_check,
            })
        return self._aggregate(results)
```

**评估维度**:
- 框架匹配度 (LLM 判断: 内容使用的框架与预期框架是否一致)
- 组件覆盖率 (框架的 components 在内容中是否被覆盖)
- 数据支撑度 (框架分析是否有对应的 evidence_required)
- 逻辑一致性 (因果链完整性)

**前置**: MKB 框架库必须有带 `components` 和 `evidence_required` 的结构化定义

### 4.2 Layer 3: 分析深度评估

**当前 LLM Judge** (`llm_judge.py`, 已修) 升级为完整的 LLM-as-Judge:

| 改造项 | 当前 (llm_judge.py) | 目标 |
|--------|---------------------|------|
| model | cheap_model (`:72`) | default_model |
| temperature | 0.3 (`:78`) | 0.2 |
| 重试 | 无 | max_retries=2 |
| 截断 | 4000 字符 (`:62`,`:101`) | 8000 字符 |
| 评分维度 | 4维 (30/25/25/20) | 5维 rubric 动态加载 |
| rubric 来源 | 硬编码 prompt | MKB QualityRubric |
| 回退 | ✅ 40.0(`:41`) / 35.0(`:43`) | 保持 |

**5 维评分 (与 rubric 对齐)**:
1. 洞察力 (25%) — 是否有超越陈述事实的分析洞见
2. 逻辑链完整性 (25%) — 因果推断是否自洽闭合
3. 数据批判性 (20%) — 是否标注来源/置信度/口径
4. 前瞻性 (15%) — 是否提供可验证的预测/情景
5. 可验证性 (15%) — 结论能否被第三方的数据和方法复现

### 4.3 三层融合

```python
class SemanticQualityScorer:
    async def score(self, content, section_type, framework=None):
        layer1 = await self._layer1_structure(content, section_type)
        if layer1.score < 30:  # 结构不完整 → 跳过深层评分
            return SectionScore(total=layer1.score, layers={"structure": layer1})

        layer2 = await self._layer2_methodology(content, section_type, framework)
        layer3 = await self._layer3_depth(content, section_type)
        total = layer1.score * 0.25 + layer2.score * 0.40 + layer3.score * 0.35
        return SectionScore(total=round(total, 1), layers={...})
```

**权重逻辑**: Layer 1 权重最低 (25%) 因为是对"写作规范"的检查；Layer 2 (40%) 是核心——方法论应用质量是我架构设计的核心差异点；Layer 3 (35%) 是对最终输出质量的端到端判断。
