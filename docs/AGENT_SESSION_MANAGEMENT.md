# Agent Session Hierarchy Management Design

> **Document Version**: v1.0  
> **Created**: 2026-04-10  
> **Priority**: P0 (Critical Architecture Defect Fix)  
> **Related Documents**: AGENT_ARCHITECTURE.md, CORE_ARCHITECTURE.md

---

## Problem Background

### Discovered Architecture Defect

During review of Zensers' Agent collaboration mechanism, the following **critical defects** were discovered:

| Defect | Description | Impact |
|--------|-------------|--------|
| **No Session Binding** | Agents created without independent Session | Unable to track Agent lifecycle |
| **No Hierarchy** | Unable to track parent-child Session relationships | Master doesn't know which sub-Agents were created |
| **No Status Tracking** | Master cannot know sub-Agent execution progress | Unable to implement progress monitoring |
| **No Async Collection** | Unable to implement event-driven result aggregation | Can only synchronously block and wait |

### Root Cause

**Missing Design Documentation**: Previous architecture design documents focused on "static structure" descriptions, lacking "dynamic behavior" and "runtime collaboration" design.

---

## 1. Design Goals

### 1.1 Core Problem

> **After a task is initiated, the Agent Factory produces a large number of Agents. How are the sub-Sessions generated by these Agents managed? How does the master Agent know the progress and results of sub-Agents?**

### 1.2 Design Goals

1. **Hierarchy Tracking**: Each sub-Agent Session records parent_session_id
2. **Status Synchronization**: Sub-Agents publish status events through MessageBus
3. **Async Collection**: ResultCollector supports waiting for individual/all Agents to complete
4. **Origin Distinction**: SessionOrigin distinguishes primary/spawned/background
5. **Progress Monitoring**: Supports real-time progress tracking

---

## 2. Architecture Design

### 2.1 Session Hierarchy Architecture

```

│  ParentSession (Master Session)                                │
│  ├── session_id: "research_abc123"                          │
│  ├── parent_id: None                                        │
│  ├── AgentSessionRegistry (Sub-Session Registry)                 │
│  │   ├── child_sessions["agent_1_session"]                  │
│  │   ├── child_sessions["agent_2_session"]                  │
│  │   └── child_sessions["agent_3_session"]                  │
│  │                                                          │
│  ├── ResultCollector (Result Collector)                           │
│  │   └── Subscribes to agent.completed event                │
│  │                                                          │
│  └── MessageBus (Event Communication)                                  │
│      ├── agent.started -> Sub-Agent starts                  │
│      ├── agent.progress -> Sub-Agent progress               │
│      └── agent.completed -> Sub-Agent completes             │
│                                                             │
│          ┌──────────┼──────────┐                            │
│          ▼          ▼          ▼                            │
│  ┌────────────┐ ┌────────────┐ ┌────────────┐               │
│  │ChildSession│ │ChildSession│ │ChildSession│               │
│  │ agent_1    │ │ agent_2    │ │ agent_3    │               │
│  │ parent_id: │ │ parent_id: │ │ parent_id: │               │
│  │ Master ID  │ │ Master ID  │ │ Master ID  │               │
```

### 2.2 Runtime Flow

```
┌─────────────────────────────────────────────────────────────┐
│  Agent Collaboration Complete Process                                        │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  1. User initiates request                                             │
│     └── Orchestrator creates master Session                          │
│                                                             │
│  2. Agent creation phase                                            │
│     ├── Factory.create_agent_with_session()                 │
│     ├── Create independent Session for each Agent                           │
│     ├── Register in AgentSessionRegistry                          │
│     └── Set parent_session_id                               │
│                                                             │
│  3. Task distribution phase                                             │
│     ├── Publish agent.started event                              │
│     ├── Update Session status to RUNNING                            │
│     └── Execute Agent tasks in parallel                                    │
│                                                             │
│  4. Execution monitoring phase                                             │
│     ├── Agent periodically publishes agent.progress event                    │
│     ├── Master queries status through Registry                             │
│     └── ResultCollector collects results                             │
│                                                             │
│  5. Result aggregation phase                                             │
│     ├── Agent completes, publishes agent.completed event                 │
│     ├── ResultCollector asynchronously collects results                         │
│     └── Update Session status to COMPLETED                          │
│                                                             │
│  6. Final integration phase                                             │
│     ├── wait_for_all() waits for all Agents to complete                     │
│     ├── Aggregate all results                                         │
│     └── Generate final report                                         │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

```python
# File: src/core/agents/agent_session.py

from dataclasses import dataclass, field
from datetime import datetime
from typing import Any, Dict, Optional
from enum import Enum

class AgentSessionStatus(Enum):
    """Agent Session Status"""
    PENDING = "pending"       # Pending execution
    RUNNING = "running"       # Executing
    COMPLETED = "completed"   # Completed
    FAILED = "failed"         # Failed
    CANCELLED = "cancelled"   # Cancelled

class SessionOrigin(Enum):
    """Session Origin"""
    PRIMARY = "primary"       # Master Session
    SPAWNED = "spawned"       # Sub-Session created by master
    BACKGROUND = "background" # Background task Session

@dataclass
class AgentSession:
    """
    Agent Session - Agent execution context
    
    Each Agent has an independent Session, forming a hierarchy with the parent Session
    Reference: OMO TaskSessionState
    """
    session_id: str                          # Session unique identifier
    agent_id: str                            # Associated Agent ID
    parent_session_id: Optional[str] = None  # Parent Session ID
    origin: SessionOrigin = SessionOrigin.PRIMARY
    
    # Status
    status: AgentSessionStatus = AgentSessionStatus.PENDING
    progress: float = 0.0                    # Progress 0-1
    result: Optional[Dict[str, Any]] = None  # Execution result
    
    # Metadata
    created_at: datetime = field(default_factory=datetime.now)
    started_at: Optional[datetime] = None
    completed_at: Optional[datetime] = None
    
    # Task information
    task: Optional[Dict[str, Any]] = None
    context: Dict[str, Any] = field(default_factory=dict)
```

### 3.2 AgentSessionRegistry

```python
# File: src/core/agents/agent_session.py (continued)

@dataclass
class AgentSessionRegistry:
    """
    Agent Session Registry
    
    Tracks all sub-Agent Sessions under the master Session
    Reference: OMO BoulderState.session_ids + session_origins
    """
    parent_session_id: str
    child_sessions: Dict[str, AgentSession] = field(default_factory=dict)
    
    def register(self, session: AgentSession) -> None:
        """Register a sub-Session"""
        session.parent_session_id = self.parent_session_id
        self.child_sessions[session.session_id] = session
    
    def get_session(self, session_id: str) -> Optional[AgentSession]:
        """Get a Session"""
        return self.child_sessions.get(session_id)
    
    def get_by_agent(self, agent_id: str) -> Optional[AgentSession]:
        """Get Session by Agent ID"""
        for session in self.child_sessions.values():
            if session.agent_id == agent_id:
                return session
        return None
    
    def update_status(
        self, 
        session_id: str, 
        status: AgentSessionStatus,
        progress: Optional[float] = None,
        result: Optional[Dict] = None
    ) -> None:
        """Update Session status"""
        session = self.child_sessions.get(session_id)
        if session:
            session.status = status
            if progress is not None:
                session.progress = progress
            if result is not None:
                session.result = result
    
    def get_all_status(self) -> Dict[str, Dict]:
        """Get all Session status summaries"""
        return {
            sid: {
                "agent_id": s.agent_id,
                "status": s.status.value,
                "progress": s.progress,
                "has_result": s.result is not None
            }
            for sid, s in self.child_sessions.items()
        }
    
    def get_pending(self) -> List[AgentSession]:
        """Get pending Sessions"""
        return [s for s in self.child_sessions.values() 
                if s.status == AgentSessionStatus.PENDING]
    
    def get_running(self) -> List[AgentSession]:
        """Get running Sessions"""
        return [s for s in self.child_sessions.values() 
                if s.status == AgentSessionStatus.RUNNING]
    
    def get_completed(self) -> List[AgentSession]:
        """Get completed Sessions"""
        return [s for s in self.child_sessions.values() 
                if s.status == AgentSessionStatus.COMPLETED]
```

### 3.3 ResultCollector

```python
# File: src/core/agents/result_collector.py

import asyncio
from dataclasses import dataclass, field
from datetime import datetime
from typing import Any, Dict, List, Optional
from src.core.communication import MessageBus, Event, SharedMemory

@dataclass
class ResultCollector:
    """
    Result Collector
    
    The master Agent collects sub-Agent results through this mechanism
    """
    parent_session_id: str
    message_bus: MessageBus
    shared_memory: SharedMemory
    
    _results: Dict[str, Dict[str, Any]] = field(default_factory=dict)
    _completion_events: Dict[str, asyncio.Event] = field(default_factory=dict)
    
    async def setup(self) -> None:
        """Set up event listeners"""
        await self.message_bus.subscribe(
            f"session.{self.parent_session_id}.agent.completed",
            self._handle_agent_completed
        )
    
    async def _handle_agent_completed(self, event: Event) -> None:
        """Handle Agent completion event"""
        data = event.data
        session_id = data.get("session_id")
        
        self._results[session_id] = {
            "session_id": session_id,
            "agent_id": data.get("agent_id"),
            "result": data.get("result"),
            "completed_at": datetime.now().isoformat()
        }
        
        if session_id in self._completion_events:
            self._completion_events[session_id].set()
    
    async def wait_for_agent(
        self, 
        session_id: str, 
        timeout: Optional[float] = None
    ) -> Optional[Dict[str, Any]]:
        """Wait for a specific Agent to complete"""
        if session_id in self._results:
            return self._results[session_id]
        
        if session_id not in self._completion_events:
            self._completion_events[session_id] = asyncio.Event()
        
        event = self._completion_events[session_id]
        
        try:
            await asyncio.wait_for(event.wait(), timeout=timeout)
            return self._results.get(session_id)
        except asyncio.TimeoutError:
            return None
    
    async def wait_for_all(
        self, 
        session_ids: List[str],
        timeout: Optional[float] = None
    ) -> Dict[str, Optional[Dict[str, Any]]]:
        """Wait for all Agents to complete"""
        tasks = [
            self.wait_for_agent(sid, timeout)
            for sid in session_ids
        ]
        results = await asyncio.gather(*tasks, return_exceptions=True)
        
        return {
            sid: result if not isinstance(result, Exception) else None
            for sid, result in zip(session_ids, results)
        }
    
    def get_results(self) -> Dict[str, Dict[str, Any]]:
        """Get all collected results"""
        return self._results.copy()
```

### 4.1 DynamicAgentFactory Extension

```python
# File: src/core/agents/factory.py (modified)

class DynamicAgentFactory:
    """Dynamic Agent Factory (Extended Version)"""
    
    def __init__(
        self, 
        skill_registry: Optional[SkillRegistry] = None,
        message_bus: Optional[MessageBus] = None,
        shared_memory: Optional[SharedMemory] = None
    ):
        self._skill_registry = skill_registry or SkillRegistry()
        self._message_bus = message_bus
        self._shared_memory = shared_memory
        
        # New: Session registries
        self._session_registries: Dict[str, AgentSessionRegistry] = {}
    
    def create_agent_with_session(
        self,
        agent_id: str,
        capability: AgentCapability,
        parent_session_id: str,
        context: Optional[Dict[str, Any]] = None
    ) -> tuple[BaseAgent, AgentSession]:
        """
        Create an Agent and bind a Session
        
        This is the key method - solves the problem of untracked Agents after creation
        """
        # 1. Create Agent
        agent = self.create_agent(agent_id, capability, context)
        
        # 2. Create Agent Session
        session = AgentSession(
            session_id=f"agent_{uuid.uuid4().hex[:8]}",
            agent_id=agent_id,
            parent_session_id=parent_session_id,
            origin=SessionOrigin.SPAWNED,
            task={"action": "research", "aspect": context.get("aspect")},
            context=context or {}
        )
        
        # 3. Register in parent Session's registry
        if parent_session_id not in self._session_registries:
            self._session_registries[parent_session_id] = AgentSessionRegistry(
                parent_session_id=parent_session_id
            )
        
        self._session_registries[parent_session_id].register(session)
        
        # 4. Inject communication capabilities into the Agent
        agent._session = session
        agent._message_bus = self._message_bus
        agent._shared_memory = self._shared_memory
        
        return agent, session
```

### 4.2 ResearchOrchestrator Integration

```python
# File: src/core/orchestrator/research_orchestrator.py (modified)

class ResearchOrchestrator:
    """Research Task Master Scheduler (Extended Version)"""
    
    def __init__(
        self,
        # ... original parameters ...
        message_bus: Optional[MessageBus] = None,
        shared_memory: Optional[SharedMemory] = None,
    ):
        # ... original initialization ...
        self.message_bus = message_bus or MessageBus()
        self.shared_memory = shared_memory or SharedMemory()
        
        # New: Master Session and Result Collector
        self._primary_session_id: Optional[str] = None
        self._session_registry: Optional[AgentSessionRegistry] = None
        self._result_collector: Optional[ResultCollector] = None
    
    async def _execute_research(
        self,
        agents: List[BaseAgent],
        requirement: ResearchRequirement
    ) -> List[Dict[str, Any]]:
        """Execute research flow (Extended Version)"""
        
        # 1. Create master Session
        self._primary_session_id = f"research_{uuid.uuid4().hex[:8]}"
        self._session_registry = AgentSessionRegistry(
            parent_session_id=self._primary_session_id
        )
        
        # 2. Create Result Collector
        self._result_collector = ResultCollector(
            parent_session_id=self._primary_session_id,
            message_bus=self.message_bus,
            shared_memory=self.shared_memory
        )
        await self._result_collector.setup()
        
        # 3. Create Session for each Agent
        session_ids = []
        for agent in agents:
            _, session = self.factory.create_agent_with_session(
                agent_id=agent.agent_id,
                capability=AgentCapability(
                    name=agent.config.get("name"),
                    description=agent.config.get("description"),
                    required_skills=agent.config.get("required_skills", []),
                ),
                parent_session_id=self._primary_session_id,
                context={"topic": requirement.topic}
            )
            session_ids.append(session.session_id)
        
        # 4. Execute Agents in parallel (with event tracking)
        async def execute_with_tracking(agent: BaseAgent, session_id: str):
            await self.message_bus.publish(
                f"session.{self._primary_session_id}.agent.started",
                Event(type="agent.started", data={"session_id": session_id})
            )
            
            try:
                result = await agent.run(agent.config.get("task", {}))
                
                await self.message_bus.publish(
                    f"session.{self._primary_session_id}.agent.completed",
                    Event(type="agent.completed", data={
                        "session_id": session_id,
                        "agent_id": agent.agent_id,
                        "result": result
                    })
                )
                return result
            except Exception as e:
                await self.message_bus.publish(
                    f"session.{self._primary_session_id}.agent.failed",
                    Event(type="agent.failed", data={
                        "session_id": session_id,
                        "agent_id": agent.agent_id,
                        "error": str(e)
                    })
                )
                raise
        
        # 5. Execute in parallel
        tasks = [
            execute_with_tracking(agent, sid)
            for agent, sid in zip(agents, session_ids)
        ]
        results = await asyncio.gather(*tasks, return_exceptions=True)
        
        # 6. Wait for all results
        collected = await self._result_collector.wait_for_all(session_ids)
        
        return list(collected.values())
```

## 8. Summary

This document fills the critical gap in Zensers architecture design:

1. **AgentSession**: Each Agent is bound to an independent Session
2. **AgentSessionRegistry**: Tracks all sub-Agent Sessions
3. **ResultCollector**: Event-driven result collection
4. **SessionOrigin**: Distinguishes Session origin types

These designs reference OMO's TaskSessionState and session_origins mechanisms, while adapting to Zensers' independent runtime environment.
