### 3. Bug Fixes - Null Value Handling

#### Issue 1: `_clean_inline_markdown` method structural break
**Cause**: When the smart chart feature was added, code was incorrectly placed inside the `_should_generate_charts` method
**Symptoms**: 
- `'NoneType' object has no attribute 'replace'`
- `can only concatenate str (not "NoneType") to str`

**Fix**: `src/agents/fixed_agents/document_generation_agent.py`
- Moved `return text` back to end of `_clean_inline_markdown` method
- Fixed null value check in table filtering (lines 548, 607)

#### Issue 2: `element.get(key, "")` does not defend against explicit `None` values
**Cause**: When key exists but value is `None`, default value does not take effect

**Fix**: 
- `src/core/orchestrator/output/document_generator.py` - Changed to `element.get(key) or ""`
- `src/converters/html_to_word.py` - Added null value defense for table cells and fallback paths

### 4. Cover, Table of Contents, Chart Fixes

#### Issue 1: Cover title position too low
**Cause**: 8 empty paragraphs simulated padding-top: 200px, pushing the title to 1/3 of the page

**Fix**: `src/converters/html_to_word.py` - Changed to 3 empty paragraphs, title positioned in upper 1/3 of page (centered above middle)

#### Issue 2: Table of contents text lost
**Cause**: `</a>` tag processing in `base_parser.py` returned directly, causing text not to accumulate

**Fix**: `src/converters/base_parser.py` - Do not `return` after `</a>` tag processing, let text continue accumulating

#### Issue 3: Chart generation conditions too strict
**Cause**: Section title must contain specific keywords to generate charts

**Fix**: `src/agents/fixed_agents/document_generation_agent.py` - Relaxed keyword list, added generic keywords like "analysis", "data", "statistics", "scale", "landscape"

## Part 7: Prompt Trace Cleanup (Fixing at Data Structure Level)

**Problem**: LLM response content contains prompt traces, such as "OK, received your comprehensive analysis task..."

**Root Cause** (Oracle analysis):
1. Missing system_prompt to constrain LLM behavior
2. User prompt mixes "data" and "instructions" at the same level
3. Verbose headings like "Analysis Requirements", "Prohibited Behaviors" are easily repeated by LLM

**Fix Plan** (At data structure level):

1. **Add system_prompt** (`generic_agent.py:313`)
   - Constrain LLM output format
   - Prohibit conversational prefixes and prompt repetition

2. **Simplify prompt structure** (`generic_agent.py:1450-1479, 1660-1672`)
   - Use `---` delimiter to clearly separate data area and instruction area
   - Remove verbose headings like "Analysis Requirements", "Prohibited Behaviors"
   - Streamline instructions to one sentence

**Modified File**: `src/core/agents/generic_agent.py`
